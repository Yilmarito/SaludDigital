PASO 3 — Cómo funciona / How it works
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ES: 1. Copia tu archivo de video a la carpeta videos/
         con el nombre exacto indicado arriba.
      2. Abre (o recarga) la página en tu navegador.
      3. El reproductor aparecerá automáticamente.
         Si el archivo no está presente, se muestra
         un placeholder con el nombre del archivo esperado.
      4. Haz clic en el botón ▶ para reproducir.

  EN: 1. Copy your video file to the videos/ folder
         using the exact filename shown above.
      2. Open (or reload) the page in your browser.
      3. The player will appear automatically.
         If the file is missing, a placeholder shows
         the expected filename.
      4. Click the ▶ button to play.

NOTA IMPORTANTE / IMPORTANT NOTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ES: Los navegadores modernos tienen restricciones de seguridad
      que bloquean la carga de archivos locales cuando abres el
      HTML directamente (file://). Para que los videos funcionen
      correctamente, sirve la carpeta con un servidor local:

        → Con VS Code: instala la extensión "Live Server"
          y haz clic en "Go Live"
        → Con Python: abre la terminal en la carpeta raíz y ejecuta:
          python -m http.server 8000
          Luego abre: http://localhost:8000

  EN: Modern browsers have security restrictions that block
      local file loading when you open HTML directly (file://).
      For videos to work correctly, serve the folder with a
      local server:

        → With VS Code: install the "Live Server" extension
          and click "Go Live"
        → With Python: open terminal in the root folder and run:
          python -m http.server 8000
          Then open: http://localhost:8000
